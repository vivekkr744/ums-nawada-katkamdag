🔥 Firebase Setup Guide — Cloud Storage Activate Karo

One-time setup only. After this, data can be accessed from any device.

1
Open Firebase Console: Go to console.firebase.google.com → Sign in with Google account → Click "Create a project" → Project name: UMS-Nawada-Katkamdag
2
Enable Realtime Database: Left sidebar → "Build" → "Realtime Database" → "Create Database" → Region: Asia Southeast → Select "Start in test mode"
3
Enable Authentication: "Build" → "Authentication" → "Get started" → "Sign-in method" tab → Enable "Email/Password"
4
Create Admin User: Authentication → "Users" tab → "Add user" → Email: admin@umsnawada.edu → Password: 1234 (can be changed later from Admin Settings)
5
Register Web App: Project Settings (⚙️) → "Your apps" → "</>" icon → App nickname: UMS Admin → Register → Copy the config code
6
Paste Config in this file: Open this HTML file in Notepad/VS Code → Find the firebaseConfig section → Paste your copied config there → Save the file → Refresh in browser ✅
